Especificación Completa del Sistema Multi-Agente de IA

Documento Unificado: PRD, TRD y Plan de Implementación Cronometrado

Este documento contiene toda la arquitectura conceptual, técnica y el cronograma preciso para el desarrollo del sistema automatizado de captación, estrategia de contenidos y generación de motion graphics mediante orquestación híbrida de LLMs (CrewAI, OpenAI y Anthropic Claude).

1. PRD (Product Requirement Document)

1.1. Visión del Producto

Automatizar los flujos operativos repetitivos y creativos de una agencia de diseño moderna. El sistema busca prospectar inteligentemente clientes potenciales con deficiencias digitales, generar estrategias personalizadas de contenido, y delegar la conceptualización de Motion Graphics de manera automática y estructurada.

1.2. Objetivos Principales

  • Reducción de Tiempos Creativos: Pasar de 5 días a un promedio de 4 horas en la estructuración de propuestas de contenido y wireframes visuales.
  • Prospección Autónoma: Identificar un mínimo de 3 a 5 prospectos comerciales altamente cualificados por ciclo de ejecución sin intervención humana manual.
  • Automatización del Alcance: Redactar correos personalizados listos para enviar por SMTP conteniendo el presupuesto estimado.

1.3. Perfiles de Agentes (Estructura de la Crew)

Agente Rol / Misión LLM Motor Output Esperado
Prospector Comercial Escanear la web en nichos específicos detectando debilidades de marca y diseño. GPT-4o-mini Diccionario con datos del cliente y análisis de fallas en su presencia digital.
Estratega de Contenidos Desarrollar la estrategia narrativa, pilares de contenido y conceptos visuales. Claude 3.5 Sonnet Guión técnico desglosado con especificaciones estéticas detalladas.
Director de Motion/Video Traducir la estrategia en código reproducible de animación para generar videos. Claude 3.5 Sonnet Código nativo estructurado (Remotion / JavaScript o Manim / Python).
Ejecutivo de Cuentas Consolidar la información, estimar costos y automatizar el correo de contacto. GPT-4o-mini Email persuasivo personalizado e inyección en el módulo SMTP.

2. TRD (Technical Requirements Document)

2.1. Stack Tecnológico

  • Lenguaje Base: Python 3.11 o superior.
  • Framework Principal: CrewAI + CrewAI Tools (para el manejo nativo del flujo asíncrono y secuencial).
  • Conectores API: Anthropic API SDK (`anthropic`), OpenAI API SDK (`openai`), y Serper.dev API para búsquedas en Google.
  • Motor de Video de Destino: Remotion (Node.js/React) o Manim (Python Community Edition). Se selecciona Manim para este documento por consistencia directa con el entorno nativo del agente.

2.2. Arquitectura de Directorios (Repositorio Listo para GitHub)

2.3. Gestión de Datos y Seguridad

  • Protección de API Keys: El archivo `.gitignore` debe prohibir estrictamente la indexación del archivo `.env`.
  • Manejo de Errores e Iteración Limitada: Todos los agentes que tengan acceso a herramientas de navegación (Serper) deben tener la bandera `max_iter=3` configurada de forma estricta para mitigar bucles infinitos de consumo en producción.

2.4 Estrategia de Conexión a Plataforma de Video (Claude API)

Para lograr la interacción fluida con la plataforma de video por código, el Agente Director de Motion pasará las especificaciones del guión creativo a una instancia directa de Claude 3.5 Sonnet a través de su API estructurada, solicitando explícitamente código ejecutable sin explicaciones textuales externas.

A continuación se define el código core del adaptador que se integrará dentro del directorio de src/tools/video_tool.py:

import anthropic
import os

def generar_codigo_animacion(guion_estratega: str) -> str:
    """
    Llama directamente a la API de Anthropic Claude 3.5 Sonnet para traducir
    el guión estratégico de la agencia en código de animación limpio para Manim (Python).
    """
    client = anthropic.Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))
    
    prompt_sistema = (
        "Eres un programador experto en animaciones de Motion Graphics usando la librería Manim de Python. "
        "Tu única tarea es recibir un guión y transformarlo en código de Python funcional estructurado en una clase "
        "que herede de 'Scene'. Devuelve EXCLUSIVAMENTE el código limpio dentro de bloques de marcado, sin introducciones ni textos de saludo."
    )
    
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=4000,
        temperature=0.2,
        system=prompt_sistema,
        messages=[
            {"role": "user", "content": f"Por favor genera la animación para el siguiente guión de diseño:\n{guion_estratega}"}
        ]
    )
    
    return response.content[0].text

3. Plan de Implementación y Tiempos de Desarrollo

Tomando en cuenta que cuentas con conocimientos previos en Python, la duración estimada total para un Producto Mínimo Viable (MVP) es de 21 a 28 días corridos dedicando una carga horaria estimada de 2 horas al día.

3.1. Cronograma Semanal Detallado

Semana 1: Infraestructura Base y Repositorio Seguro (Días 1 a 7)

  • Día 1-2: Inicialización del entorno con VS Code, creación del entorno virtual (`venv`) e instalación de las dependencias troncales.
  • Día 3-4: Diseño del archivo `.gitignore` y vinculación del proyecto inicial a un repositorio privado de GitHub.
  • Día 5-7: Alta de credenciales en las plataformas (OpenAI, Anthropic y Serper.dev) y testeo de conectividad de los scripts aislados en la carpeta `config/`.

Semana 2: Arquitectura del Equipo de Agentes y Modelado YAML (Días 8 a 14)

  • Día 8-10: Redacción precisa de las identidades de los agentes en el archivo `agents.yaml`. Ajuste de temperaturas y asignación de LLMs correctos.
  • Día 11-12: Definición de las dependencias secuenciales de las tareas dentro del archivo `tasks.yaml`.
  • Día 13-14: Primeras pruebas locales en consola con un flujo simulado para validar que el Prospector le entrega los datos de forma limpia al Estratega de Contenido.

Semana 3: Integración de la API de Claude y Generación de Videos (Días 15 a 21)

  • Día 15-17: Implementación del adaptador de la API de Anthropic dentro de las herramientas personalizadas del agente (`src/tools/video_tool.py`).
  • Día 18-19: Configuración del entorno local de renderizado de video (instalación de FFmpeg y dependencias del sistema operativo para Manim o Node.js).
  • Día 20-21: Pruebas de extracción de código. Ajuste de prompts del sistema de Claude para asegurar que la salida de la animación no contenga errores de sintaxis en tiempo de ejecución.

Semana 4: Módulo de Envío y Despliegue en Producción (Días 22 a 28)

  • Día 22-24: Codificación del módulo SMTP seguro en `src/tools/email_tool.py`. Conexión de variables dinámicas provenientes del agente Ejecutivo de Cuentas.
  • Día 25-26: Pruebas de fin a fin (End-to-End Test): desde la búsqueda del prospecto en Google hasta el correo final redactado en bandeja de salida y el video piloto guardado localmente.
  • Día 27-28: Refactorización final del código, subida de la versión definitiva del MVP estable a la rama principal (`main`) en GitHub y documentación final en el archivo `README.md`.
